# Module 2 : HTML, CSS, JavaScript

Ce dépôt contient le travail du Module 2 sur la création de pages web avec HTML, CSS et JavaScript.

## Contenu

- `index.html` : page d'accueil et structure HTML.
- `styles.css` : styles et présentation visuelle.
- `script.js` : interactions et comportement JavaScript.

## Objectifs

- Comprendre la structure d'une page HTML.
- Apprendre à styliser avec CSS.
- Ajouter des interactions simples avec JavaScript.

## Utilisation

1. Ouvrir `index.html` dans un navigateur.
2. Modifier les fichiers HTML, CSS et JS selon les besoins.
